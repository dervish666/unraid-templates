# Unraid Docker Templates

Docker templates for Unraid Community Applications.

## Available Templates

### Unraid Monitor Bot

Telegram bot for monitoring Docker containers and Unraid servers.

- **Repository:** [dervish/unraidmonitorbot](https://hub.docker.com/r/dervish/unraidmonitorbot)
- **Project:** [scratch-it.co.uk](https://scratch-it.co.uk/unraidmonitorbot)
- **Support:** [Unraid forum thread](https://forums.unraid.net/topic/197009-support-unraid-monitor-bot/)

### PanelsXR

WebXR comic reader that streams a self-hosted Komga library into a Meta Quest 3 headset. VR needs HTTPS.

- **Repository:** [dervish/panelsxr](https://hub.docker.com/r/dervish/panelsxr)
- **Project:** [GitHub](https://github.com/dervish666/PanelsXR)
- **Support:** [Issues](https://github.com/dervish666/PanelsXR/issues)

### Readarr Redux

Ebook and audiobook manager for Usenet and BitTorrent users, an unofficial continuation of Readarr.

- **Repository:** [dervish/readarr-redux](https://hub.docker.com/r/dervish/readarr-redux)
- **Project:** [GitHub](https://github.com/dervish666/readarr-redux)
- **Support:** [Unraid forum thread](https://forums.unraid.net/topic/201024-support-readarr-redux/)

## Installation

These templates are available through Unraid's Community Applications plugin.

1. Install the Community Applications plugin from Unraid's Apps tab
2. Search for "Unraid Monitor Bot", "PanelsXR" or "Readarr Redux"
3. Click Install and configure the required variables
